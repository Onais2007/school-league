# دوري المدرسة لكرة القدم

صفحة عرض عامة للدوري تعمل على GitHub Pages.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة العامة التي يراها الطلاب. |
| `admin.html` | صفحة إدخال النتائج والهدافين والمرشحين لأفضل لاعب وصورهم. |
| `results.json` | ملف النتائج. الصفحة العامة تقرأ منه. |

## الإعداد (مرة واحدة)

1. أنشئ مستودعًا جديدًا على GitHub (عام).
2. ارفع الملفات الثلاثة إلى جذر المستودع عبر: Add file ← Upload files.
3. من Settings ← Pages اختر: Deploy from a branch، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقائق يظهر رابط الموقع، وهو الرابط الذي تشاركه مع الطلاب.
   صفحة الإدارة على الرابط نفسه مضافًا إليه `admin.html`.

## تحديث النتائج بعد كل مباراة

1. افتح `admin.html` من الموقع على جهازك.
2. أدخل:
   - النتائج.
   - الهدافين والمرشحين لأفضل لاعب، من تبويب "تفاصيل المباريات".
   - الصور.
   - عدد الأصوات من نموذج التصويت.

   تعديلاتك تُحفظ تلقائيًا في متصفح هذا الجهاز.
3. اضغط **تنزيل results.json**.
4. في المستودع: Add file ← Upload files ← ارفع الملف الجديد، فيحل محل القديم ← Commit changes.
5. تظهر النتائج للطلاب خلال دقائق.

## ملاحظات

- **صفحة الإدارة لا تحتاج كلمة مرور.** أي شخص يفتحها لا يستطيع تغيير الموقع، لأن النشر يتطلب رفع الملف إلى مستودعك.
- **اعمل من جهاز واحد.** إذا أدخلت من جهاز آخر فابدأ بزر "تحميل النسخة المنشورة"، حتى لا تنشر نسخة قديمة.
- **الصور تُحفظ داخل `results.json`.** تُصغَّر تلقائيًا إلى 220 بكسل لتبقى خفيفة.
- **المستودع العام وملفاته مقروءة للجميع.** لا ترفع إلا ما أذن به أولياء الأمور.
